# Retrofit SC

A minimalistic landing page for **Retrofit SC**, a retrofit consulting company offering:

- Consulting
- Coordination
- Desktop Auditing

## 🌐 Live Demo

> You can deploy this site using [Netlify](https://www.netlify.com/) or [GitHub Pages](https://pages.github.com/).

## 🚀 Getting Started

1. Clone the repository or download the `index.html` file.
2. Open `index.html` in your browser to view the site locally.
3. To go live:
   - Upload this file to a GitHub repository
   - Connect the repo to Netlify or enable GitHub Pages

## 🎨 Design

- Built with [Tailwind CSS](https://tailwindcss.com/)
- Color palette matches Retrofit SC's logo:  
  - Dark Grey, Red, Green, Orange, Blue
